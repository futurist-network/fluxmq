Экран «Каналы (топики)» — список всех каналов брокера. Проблемные каналы стоят вверху и подсвечены. Клик по строке открывает [страницу канала](/docs/channel-detail).

## Список {#list}

Над таблицей — поиск по имени и переключатель режима с числом каналов: «Все», «Поток», «Очередь», «По ключу», «С приоритетами». Фильтр сохраняется в адресе страницы, ссылкой можно поделиться.

| Колонка | Что значит |
|---|---|
| Канал | имя; системные каналы (`$system.*`) помечены бейджем **system** — только чтение |
| Режим | Поток (`stream`), Очередь (`queue`), По ключу (`keyed`) или С приоритетами (`priority`) |
| Скорость (сообщ./с) | публикаций в секунду и график за последние минуты |
| Отставание | максимальное отставание среди групп получателей канала |
| p99 | 99-й перцентиль задержки публикации (до записи на диск) |
| Получатели | число подключённых экземпляров |
| Хранится | объём данных канала на диске |
| DLQ | сколько сообщений в очереди недоставленных |
| Состояние | худшее состояние среди групп канала: «В норме», «Внимание», «Критично» |

> [!TIP]
> Отставание подсвечивается, только если канал уже не в норме и отставание больше 1000. Большое, но стабильное отставание у канала, который просто читают пачками, — не повод для тревоги; тревога — когда оно растёт.

## Создание канала {#create}

Кнопка **Создать канал** (здесь, в верхней панели или в палитре команд) открывает мастер из двух шагов. Нужна роль администратора.

### Шаг 1. Что нужно сделать? {#create-mode}

| Выбор | Режим | Примеры |
|---|---|---|
| Хранить события и переигрывать их позже (рекомендуется) | `stream` | `orders.events`, `audit.logs`, clickstream |
| Распределять задачи между обработчиками | `queue` | `email`, `image-resize`, `webhooks` |
| Сохранять порядок по клиенту или заказу | `keyed` | `payments.events` с ключом `customer_id` |
| Сначала срочные | `priority` | `support.tickets` с `flux-priority` 0–2 |

Рассылка нескольким группам получателей работает в любом режиме. Чем режимы отличаются — в статье [Основные понятия](/docs/concepts#modes).

### Шаг 2. Параметры {#create-settings}

| Поле | По умолчанию | Что задаёт |
|---|---|---|
| Имя | — | латинские буквы, цифры, `.`, `-`, `_`; до 128 символов; точки удобны для пространств имён |
| Срок хранения | 7 дней | 1 час, 24 часа, 3 дня, 7 дней, 30 дней или бессрочно; у очереди сообщения также удаляются, когда их подтвердили все группы |
| Разделы (партиции) | 8 (у очереди 1) | 1–1024; максимум параллельных получателей в группе; **после создания не меняется** |
| Ключ упорядочивания | — | у `keyed` — поле, которое отправители используют как ключ; у остальных режимов — справочно, показывается рядом с ключами |

Блок **Дополнительно**:

| Поле | По умолчанию | Что задаёт |
|---|---|---|
| Макс. число попыток доставки | 5 | сколько раз сообщение доставляется, прежде чем уйти в DLQ |
| Тайм-аут подтверждения (секунды) | 30 | доставка без подтверждения дольше этого считается неудачной попыткой |
| Задержки между попытками | `1s, 10s, 1m, 5m` | пауза перед попыткой 2, 3, …; последнее значение повторяется; единицы `ms`, `s`, `m`, `h` |
| Очередь недоставленных (DLQ) | включена | выключено — исчерпавшие попытки сообщения отбрасываются |
| Ограничение размера | без ограничений | 1 ГБ, 10 ГБ, 100 ГБ, 1 ТБ; при превышении удаляются старые сегменты |

После создания откроется страница нового канала. Тот же результат даёт REST (`POST /api/channels`) или SDK (`client.ensure_channel(…)`) — см. [Создать канал](/docs/howto-create-channel).

## Что можно сделать потом {#after}

- Изменить хранение, повторы и DLQ — вкладка [Настройки](/docs/channel-detail#settings-tab) канала.
- Удалить канал — там же, с подтверждением по имени. Удаляются все сообщения, смещения групп и DLQ канала; подключённые получатели отключаются.
- Режим, число разделов и ключ упорядочивания поменять нельзя — создайте новый канал и при необходимости перенесите сообщения [маршрутом](/docs/routing) или переигрыванием.
